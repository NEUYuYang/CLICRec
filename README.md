# CLICRec
Long- and Short-term Interest Recommendation Algorithm Based on Con-trastive Learning and Dynamic Consistency
# Abstract	
Users’ long- and short-term interests may align or diverge as interaction contexts change. Existing methods remain limited in contrastive view construction and interest relationship modeling, making it difficult to learn distinct yet complementary representations of these interests. To address these limitations, we propose CLICRec, a recommendation model based on contrastive learning and dynamic consistency for long- and short-term interest modeling. CLICRec uses static and dynamic graph link prediction as auxiliary tasks to refine user node representations for long- and short-term interests, respectively. The dynamic graph task incorporates time intervals between sessions and time spans from sessions to the recommendation timestamp to capture evolving short-term interests. The refined representations are then clustered to construct contrastive views for the two types of interests. Furthermore, CLICRec constructs long- and short-term interest prototypes in a shared recommen-dation representation space and introduces an alignment and decorrelation loss conditioned on prototype rela-tionships. When the prototypes satisfy the similarity criterion, the loss encourages alignment between the corre-sponding interest representations. When they satisfy the conflict criterion, it penalizes only representation simi-larity exceeding a predefined margin. No additional relationship constraint is imposed when the prototype rela-tionship is uncertain. A context-aware gating mechanism then adaptively fuses the long- and short-term interest representations to generate user representations for recommendation. Experiments on four real-world datasets, ML-1M, LFM-1b, Yelp, and Gowalla, demonstrate improved recommendation performance. Averaged across these datasets, the relative improvements over the best baseline for each dataset and metric are 2.6%, 2.8%, 4.2%, and 4.4% for Recall@10, Recall@20, NDCG@10, and NDCG@20, respectively. Integrating the long-term module into DIN and the short-term module into SASRec also improves recommendation performance on ML-1M and Yelp, supporting their effectiveness as independently integrated components.
